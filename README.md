# my-journal

## Prerequisites

One of:

- [Bend 2](https://github.com/bendlang/bend#get-started)
- [mise](https://mise.jdx.dev/getting-started.html), which installs the Bend
  version pinned in `mise.toml` for you

Plus clang 14+, which Bend compiles through.

## Installation

```sh
curl -fsSL https://raw.githubusercontent.com/AH-Merii/my-journal/main/install.sh | sh
```

Verify with:

```sh
mj -h
```
